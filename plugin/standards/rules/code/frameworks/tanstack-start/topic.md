# TanStack Start Architecture

How the base rules and the React rules apply to a TanStack Start application. TanStack Start mandates only its route files under `routes/`, such as `__root.tsx` and the `/` route's `index.tsx`, and its entry files `router.tsx`, `server.ts` and `client.tsx`. It mandates no folders and no names for the rest of the code: the folders and names in these rules are this pack's own conventions.
